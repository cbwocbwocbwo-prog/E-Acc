# E-Acc 법인카드 자동처리

현재 `DEVELOPMENT_GUIDE.md`의 **3단계: PG일반 사업자번호 및 외부 상호조회**를 개발 중입니다. 영수증 OCR 정확도 보완은 이후 단계에서 계속 진행합니다.

## 실행

1. `run_app.bat`을 더블클릭한다.
2. 프로그램 상단에 i-NET 아이디와 비밀번호를 입력한다. 비밀번호는 별표로만 표시된다.
3. `e-Acc 목록 불러오기` 버튼을 누른다.
4. 프로그램이 i-NET 로그인, e-Accounting 접속, 미상신 메뉴 이동, 코스트센터 검색, Excel 다운로드 및 데이터 표시를 자동 수행한다.

입력한 로그인 정보는 버튼 클릭 직후 화면에서 지워지며 파일·DB·로그·브라우저의 아이디 저장 쿠키에 저장하지 않습니다. 프로그램을 종료하기 전까지는 임시 Edge 세션의 인증 상태를 재사용하므로, 이후 영수증 검증 등 다른 메뉴 작업에서 다시 로그인하지 않습니다. 다운로드가 이미 끝난 파일을 시험하거나 장애를 우회할 때만 `다운로드 파일 직접 불러오기`를 사용합니다.

Python으로 직접 실행하려면 다음 명령을 사용합니다.

```powershell
py -3.12 main.py
```

개발 검증 시 파일을 즉시 불러오려면 파일 경로를 추가할 수 있습니다.

```powershell
py -3.12 main.py "C:\Users\user\Downloads\ExcelData.xls"
```

## 현재 제공 기능

- UTF-8 HTML 형식의 미상신내역 `.xls` 21개 열 검증
- i-NET 자동 로그인 및 임시 Edge 로그인 세션 재사용
- 자동화용 Edge에서 미상신 메뉴 이동·코스트센터 검색·엑셀 다운로드
- 카드번호·승인번호의 문자열 및 선행 0 보존
- 날짜 `YYYY-MM-DD`, 금액 원 단위 정규화
- 선택 이미지 경로를 업무 데이터에서 제외
- `카드번호 + 승인번호 + 증빙일자 + 사용금액` 중복판정
- 행별 신규·중복·오류 분리
- 내부 거래 ID 생성
- SQLite 가져오기 이력 보관
- 상태 필터와 전체 열 검색
- 선택 행과 e-Accounting 웹 그리드의 안전한 단일 행 연결
- 결재선 지정 창에서 DocIRN·CorpNo를 읽어 원본 영수증 다운로드
- 업종에 `PG일반`이 포함된 선택 행의 사업자번호 OCR·비즈노 상호조회·사용자가 연 실구매처 팝업 자동등록
- Windows 로컬 한국어 OCR로 승인번호·증빙일자·사용금액 비교
- 영수증 정상·이상 및 필드별 사유 표시
- e-Acc에서 한 건 결재 요청 후 최신 목록 재조회 및 `처리 완료`/`목록 유지` 이력 기록
- 프로그램의 `처리 결과 이력` 탭에 검증·PG 조회·결재 확인 결과 누적

## 자체 테스트

```powershell
py -3.12 -m unittest discover -s tests -v
```

사용자 이력 DB는 `%LOCALAPPDATA%\EAccAutomation\eacc.db`에 생성됩니다. 로그인 아이디와 비밀번호는 프로그램 실행 중 로그인 요청에만 사용하며 저장하지 않습니다.

자동화용 Edge는 임시 브라우저 세션으로 실행되며 프로그램 종료 시 함께 종료됩니다. 기존에 사용자가 열어 둔 개인 Edge 창과 프로필은 변경하지 않습니다.
